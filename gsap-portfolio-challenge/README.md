# GSAP Portfolio Challenge

A modern, animated developer portfolio built with React and GSAP as part of my frontend development journey.

## 🚀 Live Demo

🌐 **[View Live Website](https://sunny-gsap-portfolio.vercel.app)**

## ✨ Features

- GSAP-powered animations
- Scroll-triggered animations with ScrollTrigger
- Smooth scrolling with ScrollSmoother
- Animated hero section
- Responsive navigation
- Custom cursor interaction
- Developer journey timeline
- Interactive tech stack section
- Responsive design
- Modern dark-themed UI

## 🛠️ Tech Stack

- React
- JavaScript
- GSAP
- SCSS
- Vite
- HTML5
- CSS3
